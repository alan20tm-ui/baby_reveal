# DBZ Reveal

Proyecto listo para GitHub Pages.

## Estructura

- `index.html`
- `css/style.css`
- `js/app.js`
- `assets/milk-bebe.png`
- `assets/goku-bebe.png`
- `assets/musica.mp3`

## Publicación

1. Sube **el contenido de esta carpeta** a la raíz de tu repositorio.
2. Verifica que `index.html` aparezca en la raíz.
3. En GitHub ve a `Settings > Pages`.
4. Selecciona `Deploy from a branch`, rama `main`, carpeta `/(root)`.
5. Guarda.

## Importante

No subas la carpeta `DBZ-Reveal` como una carpeta interna. Sube directamente sus archivos y carpetas.
